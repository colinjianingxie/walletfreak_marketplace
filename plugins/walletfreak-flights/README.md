# WalletFreak · Flights

Fares, award seats and flight terms across 19 airlines and programs. Version 0.2.0. MIT licensed.

Requires `walletfreak@walletfreak` at runtime. Install core first, then `walletfreak-flights@walletfreak` with `codex plugin add` or `claude plugin install`. Start a fresh session. This package shares the core’s one browser connection and stops research if core instructions or tools are missing.
