# Alaska / Hawaiian: official sources and search guide

Programs/search aliases: Atmos Rewards, Mileage Plan (legacy), HawaiianMiles (legacy).

These are official entry points, not inventory or durable rate/benefit claims. Follow the current visible booking and loyalty navigation if a deep link moves. Verify the destination domain before a user signs in. Recheck names, terms and program participation during research.

- [Alaska booking](https://www.alaskaair.com/)
- [Hawaiian booking](https://www.hawaiianairlines.com/)
- [Atmos Rewards](https://www.alaskaair.com/atmosrewards/)
- [Program transition](https://news.alaskaair.com/loyalty/hawaiianmiles-is-now-atmos-rewards-with-more-ways-to-earn-more-destinations-to-explore-and-more-perks-to-enjoy/)

## Search steps and restrictions to verify

1. Check both Alaska and Hawaiian booking entry points and label the booking site, operating carrier and displayed program separately.
2. Atmos Rewards is the combined program; treat Mileage Plan and HawaiianMiles as legacy names, and recheck current migration/account guidance instead of asking users to transfer balances.
3. Inspect partner awards, Saver restrictions, baggage and resident/cardholder/companion benefits for the exact flight; do not assume one carrier’s inventory or terms mirror the other.
4. Open the selected rate/fare terms before any checkout. Record the shared result fields in this skill, exact search parameters and observation time. If login is needed, let the user handle it. If blocked, use clearly labeled manually supplied results.

For every flight compare the same airports, travel days, party size, segments, cabin and baggage. Disclose self-transfers, airport changes, overnight connections and separate tickets. A partner program’s award result is not confirmation in this program.
