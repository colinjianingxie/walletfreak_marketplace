# IHG: official sources and search guide

Programs/search aliases: IHG One Rewards.

These are official entry points, not inventory or durable rate/benefit claims. Follow the current visible booking and loyalty navigation if a deep link moves. Verify the destination domain before a user signs in. Recheck names, terms and program participation during research.

- [IHG booking](https://www.ihg.com/)
- [IHG One Rewards](https://www.ihg.com/onerewards/content/us/en/home)

## Search steps and restrictions to verify

1. Compare Reward Nights, cash, and Points & Cash for identical rooms and occupancy.
2. Read the Points & Cash payment and cancellation explanation; do not describe a points purchase as a refundable cash room charge.
3. Check cardholder multi-night benefits and certificate limits only for the specific eligible account; verify property fees and breakfast eligibility.
4. Open the selected rate/fare terms before any checkout. Record the shared result fields in this skill, exact search parameters and observation time. If login is needed, let the user handle it. If blocked, use clearly labeled manually supplied results.

For every room compare the same dates, number of rooms, adults/children, bed type, meals, cancellation deadline and payment timing. Show total stay cost and mandatory charges payable at the property, even when excluded from the initial displayed total.
