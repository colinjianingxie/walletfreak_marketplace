# WalletFreak core

Version 0.1.0 · MIT. Install `walletfreak@walletfreak` before any provider.

Core bundles `travel-plan`, `card-travel-benefits`, `walletfreak-setup`, the arithmetic helper and one pinned Playwright MCP browser. Providers are discovered through the host and share this browser. Users sign in and book themselves.
