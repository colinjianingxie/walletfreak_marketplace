# Citi Travel: official sources and search guide

Programs/search aliases: ThankYou Points, Hotel Collection, Luxury Collection.

These are official entry points, not inventory or durable rate/benefit claims. Follow the current visible booking and loyalty navigation if a deep link moves. Verify the destination domain before a user signs in. Recheck names, terms and program participation during research.

- [Citi Travel sign-in](https://www.citi.com/citi-partner/cititravel/login)
- [Citi Travel](https://www.cititravel.com/)

## Search steps and restrictions to verify

1. Have the user sign in with an eligible account and select the card; record portal currency and points quote.
2. Check Hotel Collection/Luxury Collection labels and property-specific terms where displayed; compare the exact room and cancellation window against direct.
3. Verify remaining hotel benefits, spend thresholds, exclusions and offer dates; do not apply an advertised offer without account and itinerary eligibility evidence.
4. Open the selected rate/fare terms before any checkout. Record the shared result fields in this skill, exact search parameters and observation time. If login is needed, let the user handle it. If blocked, use clearly labeled manually supplied results.

Portal redemption and transfers to a loyalty program are different alternatives. Verify the exact card product, market, remaining credits and benefit period without collecting account numbers. Show gross payable cost first, then a separate conditional-credit scenario. Verify whether portal bookings earn hotel loyalty credit or receive elite benefits; never assume either.
