# Qantas: official sources and search guide

Programs/search aliases: Qantas Frequent Flyer.

These are official entry points, not inventory or durable rate/benefit claims. Follow the current visible booking and loyalty navigation if a deep link moves. Verify the destination domain before a user signs in. Recheck names, terms and program participation during research.

- [Qantas booking](https://www.qantas.com/)
- [Qantas Frequent Flyer](https://www.qantas.com/au/en/frequent-flyer.html)

## Search steps and restrictions to verify

1. Distinguish Classic Flight Rewards, Classic Plus where shown, and Points Plus Pay.
2. Check partner-operated flights and full-trip cabin/seat availability; calendar indicators need a dated itinerary confirmation.
3. Record booking currency, carrier charges and change/cancel terms; compare the selected reward type with an equivalent cash fare.
4. Open the selected rate/fare terms before any checkout. Record the shared result fields in this skill, exact search parameters and observation time. If login is needed, let the user handle it. If blocked, use clearly labeled manually supplied results.

For every flight compare the same airports, travel days, party size, segments, cabin and baggage. Disclose self-transfers, airport changes, overnight connections and separate tickets. A partner program’s award result is not confirmation in this program.
