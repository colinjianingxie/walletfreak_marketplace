# WalletFreak traveler profile

Optional, self-reported planning data. Fill only what you want to share; approximate values are fine. Leave unknown fields blank or write `unknown`. Date each report as YYYY-MM-DD. Do not enter account/card numbers, passwords or redemption codes. Saving and future reuse are optional; this file is plain text.
